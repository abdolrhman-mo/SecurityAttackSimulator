# Network Security Visualizer

![Network Visualization Screenshot](screenshot.png) *(Add your screenshot here)*

A 3D interactive visualization tool that simulates network traffic and security threats in real-time, built with OpenGL and GLUT.

## Features

- **3D Network Visualization**:
  - Computers (blue cubes), routers (orange spheres), firewalls (red pyramids)
  - Animated connections with directional indicators
  - Real-time packet movement

- **Security Simulation**:
  - Normal (green), DDoS attack (red), intrusion (orange) packets
  - Encrypted (blue) and blocked (yellow) packet states
  - Adjustable firewall protection

- **Interactive Controls**:
  - Dynamic camera movement
  - Simulation pause/resume
  - Firewall toggle
  - UI customization
